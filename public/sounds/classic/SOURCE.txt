Transformation: decode Ogg Vorbis, preserve all frames and both stereo channels
at 44100 Hz, then quantize each finite sample to signed 16-bit little-endian PCM
using Math.round(sample * 32767). Write the conventional 44-byte RIFF/WAVE header.
No gain, normalization, silence/tail trimming, mixing, resampling or dithering.
No sound was synthesized. Both source files decode with zero reported errors.

Decoded/converted measurements (RMS and peak relative to PCM full scale):

The decoder and its dependency code are used only in an isolated development
directory. They are not app runtime dependencies and are not bundled with the
app. Only the package/lock metadata and our readable conversion script are
included to reproduce the CC0 audio conversion. No install scripts are run.

Reproduction from the repository root (Node.js 24 was used):
  decoder_dir="$(mktemp -d /private/tmp/kenney-convert.XXXXXX)"
  cp public/sounds/classic/decoder-package.json "$decoder_dir/package.json"
  cp public/sounds/classic/decoder-lock.json "$decoder_dir/package-lock.json"
  npm ci --prefix "$decoder_dir" --cache "$decoder_dir/cache" --ignore-scripts --no-audit --no-fund
  node public/sounds/classic/convert.mjs "$decoder_dir" "$decoder_dir/output"
  shasum -a 256 "$decoder_dir/output/move.wav" "$decoder_dir/output/capture.wav"
